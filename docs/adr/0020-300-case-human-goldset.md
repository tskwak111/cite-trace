# ADR-0020: 300-case human gold-set annotation plan

- **Status:** Proposed
- **Date:** 2026-08-30

## Context

The evaluation framework (Slice 12, ADR-0012) uses synthetic
data generated by the annotation pipeline. Synthetic data is
useful for contract testing and regression detection, but the
product requires a human-annotated gold set to:

- Calibrate the confidence vector thresholds
- Measure recall against ground-truth annotations
- Detect systematic bias in the model provider's citation
  parsing
- Produce a trustworthy precision/recall report for
  prospective customers

The target is 300 citation-level cases covering:

- 5 disciplines (CS, biomedical, social science, physics, law)
- 3 relation types (direct_support, partial_support, scope_mismatch)
- 2 work types (journal_article, conference_paper)
- Both user-uploaded and open-access source assets

## Decision

The 300-case gold-set will be produced by two trained
annotators working independently, with adjudication by a
third senior annotator for disagreements.

The annotation instrument is the CiteTrace Streamlit UI
(ADR-0016). Each annotator works through the same set of
PDFs and records their judgments in `adjudicated.jsonl`
format. The Krippendorff α (Slice 19-D) is computed from
the two independent annotations before adjudication;
α ≥ 0.75 is the inter-rater reliability gate.

Each adjudicated record carries:

```
annotator_id: str
annotation_timestamp: ISO-8601
discipline: str
source_asset_id: UUID
citing_claim_span: str
cited_doi: str | null
evidence_relation: evidence_relation
citation_intents: list[citation_intent]
transformation_kind: list[transformation_kind]
confidence_vector: dict[str, float]
access_level: access_level
notes: str  # optional annotator notes
```

The final corpus is stored in `evaluation/gold-standard/`
as `annotator_a.jsonl`, `annotator_b.jsonl`,
`adjudicated.jsonl`, and a `METADATA.yaml` describing the
annotation protocol, annotator qualifications, and
inter-rater reliability scores.

## Timeline

- Annotator recruitment and training: 1 week
- Independent annotation (300 cases × 2): 1–2 weeks
- Adjudication: 3–5 days
- Quality review: 2–3 days
- Total estimated effort: 4–6 weeks for a part-time
  annotator team of 3

## Out of scope (explicitly)

- Generating the 300 cases programmatically. The cases
  must be real PDFs selected by the team, not synthetic
  text generated by a model.
- Publishing the gold set publicly. The corpus is licensed
  per the team member agreements and is not redistributed.
- Using the gold set as a training set. The gold set is
  for evaluation only; the model is not fine-tuned on it.

## Consequences

- The Krippendorff α gate (α ≥ 0.75) is the quality
  threshold for accepting the corpus.
- The `scripts/ingest_adjudicated.py` tool (ADR-0019)
  can ingest the final `adjudicated.jsonl` into the DB.
- The evaluation framework's quality metrics can be
  re-run against the DB after ingestion to produce
  a calibrated performance report.
