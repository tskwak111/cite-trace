# Contract examples

These files are executable examples, not illustrative pseudo-JSON. `scripts/validate_package.py` validates them against the versioned JSON Schemas.

- `evidence-link.verified.v1.json`: a fully grounded scope-mismatch judgment
- `evidence-link.blocked-inaccessible.v1.json`: a lawful-access abstention with no invented evidence
- `analysis-result.completed-with-limits.v1.json`: an analysis containing both a verified and a blocked result
- `feedback.disagree.v1.json`: structured user correction feedback
