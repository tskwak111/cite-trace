# ADR-0007: Initial Scope Is English Born-Digital Scientific PDFs

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Document structure, OCR, language and layout vary widely. Claiming universal support would lower trust and make evaluation meaningless.

## Decision

Optimize the first quality gate for English born-digital scientific PDFs, initially 1–60 pages and up to 150 references, with numeric and author–year citation styles. Other documents receive explicit quality grades and limited/unsupported states.

## Consequences

- evaluation can be calibrated to a declared scope,
- OCR, multilingual and complex table reasoning remain later milestones,
- UI must disclose document quality and disabled features,
- product marketing cannot imply universal paper support.
